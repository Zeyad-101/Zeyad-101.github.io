# JobOps (Open Source Contribution)

This repository highlights my open-source contributions to JobOps, a self-hosted job-tracking platform.

**Note:** This is not a solo-owned project. This page documents my upstream contributions to the main repository.

## Overview

JobOps is a highly popular self-hosted job-tracking platform designed to help users organize their job search. With over 800 users, it frequently trends in the top-3 on GitHub for its category.

As an active contributor, I focused on expanding the platform's data acquisition capabilities and improving its infrastructure reliability. 

## Key Contributions

*   **Scraper Plugins**: Built new web scrapers for WUZZUF and Khamsat utilizing the Cheerio plugin pattern, allowing users to automatically import job postings from these platforms.
*   **Infrastructure Fixes**: Diagnosed and resolved recurring CI failures and complex Docker configuration issues, ensuring smoother deployments for all users.
