# AI Automation Pipelines

This project contains sanitized exports of the AI-powered automation workflows I built at Spinners Creative Agency.

## Overview

Managing international client accounts involves a significant amount of repetitive data entry, lead qualification, and outreach. To solve this, I engineered 5 distinct AI-powered pipelines that automate the top-of-funnel operations, saving time and increasing conversion rates.

## What it Does

These workflows connect various APIs and services to automate:
1.  **Lead Generation & Scraping**: Pulling prospect data from various sources.
2.  **Data Enrichment**: Using AI to analyze and categorize leads.
3.  **Data Synchronization**: Keeping Google Sheets (acting as a dynamic CRM) updated via Power Automate.
4.  **Automated Outreach**: Triggering personalized email sequences in Lemlist.

## Key Results

*   Eliminated **3+ hours/week** of manual data management work.
*   Closed **6 international clients** from a 100+ prospect pipeline.
*   Achieved a **~6% conversion rate**, tripling the industry average of ~2%.

## Structure

The `src/` directory contains sanitized JSON exports of the n8n workflows. Client data, API keys, and sensitive credentials have been removed.

## Tech Stack

*   n8n
*   Microsoft Power Automate
*   Google Sheets
